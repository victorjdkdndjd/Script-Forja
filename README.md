# Forja — GitHub Pages

Site estático pronto para publicar no GitHub Pages.

## Publicar

1. Envie `index.html` e `.nojekyll` para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione `main` e `/(root)`.
5. Salve.

## Editor de Scripts

O editor mantém SENÃO/SENÃO SE, grupos com E/OU/NÃO, ESPERAR, REPETIR, PARA CADA, escolha aleatória por peso, variáveis locais e expressões ƒx.

A interface foi simplificada: o **Comportamento do QUANDO**, o seletor **Entre grupos** e as **Opções avançadas da ação** foram removidos. Quando existem vários grupos, eles são combinados automaticamente com **E**.

## Addon in-game

O addon in-game segue a mesma simplificação do site e continua permitindo criar e editar os recursos acima dentro do Minecraft.

## Interface móvel
A seção **SE** usa o mesmo cartão visual de QUANDO/ENTÃO e os seletores abrem um menu próprio da Forja com busca, categorias e destaque da opção atual.
